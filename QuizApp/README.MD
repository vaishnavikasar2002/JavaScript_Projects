## Project Overview 

The Simple Quiz App is a basic web application created using HTML, CSS, and JavaScript.

It allows users to answer multiple-choice questions one at a time and provides immediate feedback by highlighting correct and incorrect answers.

After completing all questions, the app displays the user’s final score and gives an option to play again.

This project helps beginners understand how to use DOM manipulation, event handling, and JavaScript logic to make a web page interactive.

It’s a great practice project for learning frontend development fundamentals.
