# Cancer Awareness Webpage

A simple, responsive webpage designed to raise awareness about cancer, provide motivational quotes, and allow users to contact the organization for support.

---

## **Features**

- **Header Section**:  
  Displays the title and tagline to promote awareness and support.

- **Banner Section**:  
  A visually appealing banner image related to cancer awareness.

- **Motivational Quotes**:  
  - Displays inspirational quotes to encourage strength and hope.
  - Quotes automatically change every 5 seconds.
  - Users can manually change quotes using the "Change Quote" button.

- **Contact Form**:  
  - Users can submit their name, email, and message.  
  - Basic form validation is applied using `required` attributes.

- **Footer**:  
  Displays contact details and location information.

- **Responsive Design**:  
  The webpage adjusts to different screen sizes for better user experience on mobile and tablet devices.
